
# 🛡️ API Sentinel — API Testing Tool

API Sentinel is a web-based tool for sending HTTP requests and validating API responses.

## Live Demo
https://api-sentinel-e226.onrender.com

## Features
- Supports GET, POST, PUT, PATCH, and DELETE requests
- Displays HTTP status and response headers
- Measures response time and response size
- Validates expected status codes
- Checks maximum response time
- Validates JSON response bodies
- Displays individual PASS/FAIL results

## Technology Stack
- HTML and CSS
- JavaScript
- Node.js
- Express

## Run Locally
1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Run `node server.js`.
5. Open http://localhost:3000.
